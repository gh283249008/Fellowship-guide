# Fellowship 配装模拟器

一个用于游戏《Fellowship》的配装Build模拟器，帮助玩家测试不同的装备搭配方案，优化角色属性配置。

## 功能特性

### 🎮 核心功能
- **英雄选择系统**：支持多个英雄，每个英雄有独特的头像和属性，但现在只支持小鹿
- **装备选择系统**：支持游戏内14个装备槽位（头部、肩部、披风、胸部、手部、腿部、足部、项链、护腕、戒指1、戒指2、遗物1、遗物2、武器）
- **实时属性计算**：自动计算并显示所有装备带来的属性加成
- **装备筛选**：按属性筛选装备（暴击、精通、急速、灵魂）

### 💎 宝石系统
- **宝石镶嵌**：支持6种宝石类型（紫水晶、钻石、绿宝石、红宝石、蓝宝石、黄玉）
- **宝石等级**：4个等级（小型、大型、华美、无暇）
- **源质加成**：普通装备可选择0%或35%，传奇装备固定100%
- **宝石技能**：激活满足能量要求的技能，支持I级和II级技能自动替换

### 🎯 套装系统
- **套装识别**：自动识别套装装备并显示套装信息
- **套装效果**：激活套装后自动应用套装加成

### 🎨 视觉优化
- **装备边框**：根据装备的两个最高二级属性显示彩色渐变边框
  - 紫水晶色（暴击）
  - 黄玉色（急速）
  - 绿宝石色（精通）
  - 蓝宝石色（灵魂）
- **现代化UI**：深色主题界面，响应式设计
- **移动端支持**：适配手机和平板设备

## 技术栈
- **纯人机**：作者没有敲半个标点符号的代码！我们AI真的是太强啦！
- **纯前端**：HTML/CSS/JavaScript，无需后端
- **数据存储**：使用 localStorage 保存Build数据
- **数据格式**：JSON文件存储装备和套装数据
- **响应式设计**：CSS Grid 和 Flexbox 布局
- **浏览器支持**：所有现代浏览器（Chrome, Firefox, Safari, Edge）

## 浏览器支持

支持所有现代浏览器：
- Chrome (推荐)
- Firefox
- Safari
- Edge
