# Fellowship 配装模拟器

一个用于游戏《Fellowship》的配装Build模拟器，帮助玩家测试不同的装备搭配方案，优化角色属性配置。

## 功能特性

### 🎮 核心功能
- **英雄选择系统**：支持多个英雄，每个英雄有独特的头像和属性
- **装备选择系统**：支持14个装备槽位（头部、肩部、披风、胸部、手部、腿部、足部、项链、护腕、戒指1、戒指2、遗物1、遗物2、武器）
- **实时属性计算**：自动计算并显示所有装备带来的属性加成
- **Build保存/加载**：保存多个配装方案，随时切换测试
- **装备筛选**：按属性筛选装备（暴击、精通、急速、灵魂）

### 💎 宝石系统
- **宝石镶嵌**：支持6种宝石类型（紫水晶、钻石、绿宝石、红宝石、蓝宝石、黄玉）
- **宝石等级**：4个等级（小型、大型、华美、无暇），能量分别为120、240、360、480
- **源质加成**：普通装备可选择0%或35%，传奇装备固定100%
- **宝石技能**：激活满足能量要求的技能，支持I级和II级技能自动替换

### 🎯 套装系统
- **套装识别**：自动识别套装装备并显示套装信息
- **套装效果**：激活套装后自动应用套装加成
- **套装限制**：套装装备无法镶嵌宝石（`noSocket`属性）

### 📊 属性计算系统
- **递减机制**：次要属性（暴击、精通、急速、灵魂）采用递减计算
  - 0-10%：无递减
  - 10-15%：超出部分 × 95%
  - 15-20%：超出部分 × 90%
  - 20-25%：超出部分 × 85%
  - 25%以上：超出部分 × 80%
- **百分比加成**：宝石技能和套装效果的百分比加成采用加算
- **属性工具提示**：悬停查看详细属性计算过程

### 🎨 视觉优化
- **装备边框**：根据装备的两个最高二级属性显示彩色渐变边框
  - 紫水晶色（暴击）
  - 黄玉色（急速）
  - 绿宝石色（精通）
  - 蓝宝石色（灵魂）
- **现代化UI**：深色主题界面，响应式设计
- **移动端支持**：适配手机和平板设备

## 使用方法

1. **打开应用**：在浏览器中打开 `index.html` 文件
2. **选择英雄**：从下拉菜单中选择英雄
3. **选择装备**：点击装备槽位，从弹出的装备列表中选择
4. **筛选装备**：在装备选择弹窗中，使用下拉菜单按属性筛选装备
5. **镶嵌宝石**：点击装备旁的宝石插槽，选择宝石并设置源质加成
6. **查看属性**：实时查看属性面板，悬停次要属性查看详细计算过程
7. **保存Build**：点击"保存Build"按钮保存当前配装
8. **加载Build**：点击"加载Build"按钮加载已保存的配装
9. **重置**：点击"重置"按钮清空当前配装

## 属性说明

### 一级属性
- **生命值（Health）**：角色的最大生命值
- **护甲（Defense）**：减少受到的物理伤害
- **物伤减免（Physical DR）**：物理伤害减免百分比
- **魔伤减免（Magic DR）**：魔法伤害减免百分比

### 二级属性
- **耐力（Stamina）**：影响生命值上限
- **智力（Intellect）**：影响魔法值和魔法伤害

### 三级属性（次要属性）
- **暴击率（Crit Rate）**：触发暴击的概率，采用递减计算
- **精通（Mastery）**：技能效果增强，采用递减计算
- **急速（Haste）**：攻击速度和冷却缩减，采用递减计算
- **灵魂（Spirit）**：魔法恢复和效果，采用递减计算

### 四级属性
- **闪避（Dodge）**：闪避攻击的概率
- **移动速度（Move Speed）**：角色移动速度加成

### 其他属性
- **攻击力（Attack）**：物理伤害输出
- **暴击伤害（Crit Damage）**：暴击时的伤害加成
- **魔法值（Mana）**：角色的最大魔法值
- **冷却缩减（Cooldown）**：技能冷却时间减少

## 装备数据格式

装备数据存储在 `data/` 目录下的JSON文件中，每个装备类型一个文件：

- `head.json` - 头部装备
- `necklace.json` - 项链装备
- `weapon.json` - 武器装备
- `sets.json` - 套装数据

### 装备对象结构

```json
{
    "id": "3399",
    "name": "装备名称",
    "icon": "assets/icons/head/sylvie-head.png",
    "itemLevel": 330,
    "stamina": 208,
    "critRate": 397,
    "mastery": 70,
    "setId": "bel_orum_torment",
    "heroes": ["silvia"],
    "noSocket": true,
    "dropLocation": "图萨瑞之心"
}
```

### 字段说明

- `id`: 装备唯一标识符（必填，字符串）
- `name`: 装备名称（必填）
- `icon`: 图标路径（可选）
- `itemLevel`: 物品等级（可选）
- `heroes`: 适用英雄数组（可选，不填则所有英雄可用）
- `setId`: 套装ID（可选，如果属于套装）
- `noSocket`: 是否无法镶嵌宝石（可选，布尔值，true表示无法镶嵌）
- `dropLocation`: 掉落地点（可选，不显示在前端）
- 各种属性值：`stamina`, `intellect`, `critRate`, `mastery`, `haste`, `spirit`, `health`, `defense`, 等

### 套装对象结构

```json
{
    "id": "bel_orum_torment",
    "name": "贝尔奥鲁姆的折磨",
    "bonuses": [
        {
            "requiredPieces": 2,
            "description": "+4% 智力。当你的生命值低于20%时,立即恢复35%的最大生命值。该效果每180秒可触发一次。"
        }
    ]
}
```

## 测试工具

项目包含一个属性计算器测试页面 `test-calculator.html`，用于验证属性计算算法的正确性：

1. 打开 `test-calculator.html`
2. 输入基础属性值和百分比加成
3. 查看详细的计算步骤和最终结果

## 技术栈

- **纯前端**：HTML/CSS/JavaScript，无需后端
- **数据存储**：使用 localStorage 保存Build数据
- **数据格式**：JSON文件存储装备和套装数据
- **响应式设计**：CSS Grid 和 Flexbox 布局
- **浏览器支持**：所有现代浏览器（Chrome, Firefox, Safari, Edge）
